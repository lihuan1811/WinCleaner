# Product

## Register

product

## Users

Windows administrators, company IT operators, and advanced Windows users who need to clean, optimize, repair, and inspect a PC without guessing which system area a tool will touch. They usually run the app on Windows with administrator permission and care about clear risk labels, reversible actions, and direct access to real system commands.

## Product Purpose

WinCleaner is a Windows desktop utility that combines C drive cleanup, Windows optimization, software uninstall support, file management, AppData migration, system repair, restore actions, and operation logs. Success means users can scan first, understand impact, run the exact tool they need, and recover from risky operations when supported.

## Brand Personality

Practical, technical, and trustworthy. The interface should feel like a serious desktop control center, not a SaaS landing page or a decorative web dashboard.

## Anti-references

Avoid generic AI template visuals: purple gradients, heavy blur everywhere, oversized metric cards, repeated identical icon cards, fake marketing copy, and decorative motion. Avoid consumer-cleaner gimmicks that hide risk behind one-click promises.

## Design Principles

1. Make every feature feel executable, not just visible.
2. Put scan, risk, confirmation, restore, and logs near the actions they explain.
3. Use one restrained accent color for primary action and selected state.
4. Prefer dense, readable tool surfaces over decorative cards.
5. Keep dangerous operations explicit and reversible where the backend supports it.

## Accessibility & Inclusion

Target WCAG AA contrast for text and controls. All interactive controls need accessible names, visible focus behavior, keyboard access through Flutter Material controls, and clear disabled or loading reasons. Motion should be short and tied to state changes only.
